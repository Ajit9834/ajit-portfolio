# Ajit's Portfolio

A modern, interactive portfolio website built with Next.js 14, featuring a stunning 3D tubes background powered by Three.js.

## Features

- 🎨 Beautiful 3D animated background with interactive tubes
- 🌓 Dark/Light theme support
- 📱 Fully responsive design
- ⚡ Built with Next.js 14 and React 19
- 🎯 TypeScript for type safety
- 💅 Styled with Tailwind CSS 4
- 🎬 Smooth animations with Framer Motion

## Getting Started

### Prerequisites

- Node.js 18+ installed
- npm or yarn package manager

### Installation

```bash
# Clone the repository
git clone https://github.com/Ajit9834/ajit-portfolio.git

# Navigate to project directory
cd ajit-portfolio

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

## Build

```bash
# Create production build
npm run build

# Start production server
npm start
```

## Tech Stack

- **Framework:** Next.js 16.2.6
- **UI Library:** React 19.2.6
- **3D Graphics:** Three.js, React Three Fiber, React Three Drei
- **Styling:** Tailwind CSS 4.1.17
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Theme:** next-themes
- **Language:** TypeScript 5.9.3

## Deployment

This project is deployed on Vercel. Any push to the `main` branch will automatically trigger a new deployment.
